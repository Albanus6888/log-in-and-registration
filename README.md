# Login and Registration Page
### Description
This project demonstrates how to create a user-friendly login and registration page using HTML, CSS, and JavaScript. The design includes an aesthetically pleasing layout with a responsive form, modern styling, and interactivity for enhanced user experience.

![Uploading image.png…]()


### Features
##### Login and registration forms with proper input types and validation.
##### A visually appealing design with a gradient background, rounded corners, and shadows.
##### Responsive design that works on all screen sizes.
##### Password visibility toggle.
##### Real-time validation for email input.
##### Option to add social media login buttons.

### Technologies Used
##### HTML: Structure of the forms and page layout.
##### CSS: Styling for a modern and clean appearance.
##### JavaScript: Interactivity, including password visibility toggle and validation.
